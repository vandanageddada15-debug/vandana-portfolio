# Vandana Geddada – Portfolio

A responsive personal portfolio built with HTML, CSS and JavaScript.

## Files
- `index.html` – main portfolio page
- `style.css` and `responsive.css` – styling and responsive layout
- `script.js` – navigation, scroll state, reveal effects and back-to-top button
- `images/` – profile, project and certificate images
- `assets/` – supporting documents

## Publish with GitHub Pages
1. Extract the ZIP file.
2. Open the `vandana-portfolio` repository on GitHub.
3. Upload the updated files and folders to the repository root (the folder containing `index.html`).
4. Commit the changes to the branch configured for GitHub Pages (usually `main`).
5. In **Settings → Pages**, confirm that Pages is configured to deploy from the repository root.
6. Open the published Pages URL after deployment completes.

## Before publishing
- Review all profile details, project status labels and certificate dates.
- Replace `assets/resume.pdf` only after the updated resume has been finalized. The website currently labels the resume section as being updated so an older PDF is not presented as current.
- Check every external demo link and image after publishing.
